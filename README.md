# 岔路口 · 知乎围炉

> 知乎黑客松 2026 校园新锐季 S2 ·「跨次元游乐场：AI 游戏与互动叙事」参赛作品

**一句话**：从知乎热榜选一个真实困境（或写下你自己的），四位 AI 孵化的知乎答主围炉质询你、和你对线，然后陪你把这一年推演完——得到一张可以晒的命运档案。

## 玩法闭环（约 4 分钟）

1. **选题**：知乎开放平台实时拉取真实争议问题（zhihu_search）；
2. **底牌**：三张约束牌（存款水位 / 时间窗口 / 退路）决定初始处境；
3. **编译**：LLM 实时把困境编译成围炉——四位立场对立的答主、三轮质询、一次对线、十二个月事件卡、四种命运结局（schema 校验 + 偏题检测 + 24h 缓存）；
4. **围炉**：答主引用真实社区观点风格质询，你可以出应对卡，也可以**亲口打字回怼**（AI 以答主人格即兴接招，交锋质量判定影响数值）；
5. **推演**：逐月滑动事件卡，延迟后果引爆，四维「体温」见底触发现实危机；
6. **命运卡**：称号 + 判词 + 决策时间线，一键生成可分享的 PNG。

## 数据诚实性（硬约束）

- 热榜问题与赞同/评论数：来自知乎开放平台实时接口；
- 答主为 **AI 孵化的观点人格**，页面明确标注「AI 实时编译（非知乎历史）」，不伪造赞同数、不冒充真实用户；
- 断网/编译失败自动降级离线快照剧本，页面明确标注。

## 技术栈

Next.js 14 + TypeScript；LLM 走 OpenAI 兼容协议（通义千问，可切换）；知乎开放平台 API + 每小时缓存应对限额；无数据库依赖。

## 本地运行

```bash
npm install
# .env.local 需要：DASHSCOPE_API_KEY、ZHIHU_ACCESS_SECRET
npm run dev   # http://localhost:8900
```

## 目录

| 路径 | 说明 |
|---|---|
| `public/game/index.html` | 游戏主体（单文件，无构建依赖） |
| `app/api/forge/route.ts` | 困境 → 围炉编译器（核心） |
| `app/api/rebuttal/route.ts` | 打字回怼：AI 答主即兴接招 |
| `app/api/hot/route.ts` | 知乎实时争议拉取 + 缓存 |
| `lib/llm.ts` | LLM 通道封装 |
