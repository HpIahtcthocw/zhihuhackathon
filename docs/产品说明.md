# 岔路口 · 知乎围炉 —— 产品说明

> 知乎黑客松 2026 校园新锐季 S2 ·「跨次元游乐场：AI 游戏与互动叙事」
> 团队：HpIahtcthocw（单人）· 线上 Demo：见提交页 · 仓库：github.com/HpIahtcthocw/zhihuhackathon

## 一、核心创作思路

知乎上积累最多的，是**普通人为真实抉择吵过的架**：该不该裸辞、要不要转行、敢不敢回老家。这些讨论本来只属于屏幕外的围观。我们把它们变成一场可玩的游戏——

> 定位注解：游乐场里最有人气的设备往往不是过山车，是哈哈镜屋。人来这里不是解决人生，是用一种安全的方式重新看自己一眼。岔路口就是知乎社区的哈哈镜屋：进去时你是刷热榜的人，出来时你是命运卡上的人。

**从知乎热榜选一个真实困境（或写下你自己的），四位 AI 孵化的知乎答主围炉质询你、和你对线，然后陪你把这一年推演完。**

三个设计支点：

1. **真实内容进场**：困境来自知乎开放平台实时热榜与搜索（含真实赞同/评论数），答主的论证风格孵化自真实回答与精选评论的「典型观点」；
2. **AI 当编译器，不当中介**：LLM 把困境实时编译成围炉规则（四位立场对立的答主、三轮质询、一次 6 秒限时对线、十二个月事件卡、四种命运结局），并支持玩家**亲口打字回怼**、由 AI 以答主人格即兴接招——AI 改变的是可观察的游戏状态，不是替玩家写一篇漂亮话；
3. **命运对照可分享**：结算产出带称号、判词、决策时间线的命运档案图——这是社交货币，也是给人气奖引流的入口。

**目标用户**：18-30 岁学生与毕业三年内的职场新人——正在被实习/裸辞/考研/城市选择困扰、习惯在知乎搜「该不该」的人。

## 二、用户如何完成核心体验（约 4 分钟）

1. 首页「知乎热榜 · 实时争议」选一个真实问题，或一句话写下自己的困境；
2. 出三张底牌：存款水位 / 时间窗口 / 退路——决定初始处境，也会被答主当场引用；
3. 围炉编译（展示编译过程，结果 24 小时缓存，热门困境秒开）；
4. **围炉听证**：四份回答卡（实时人气投票）→ 三轮质询，每轮可出应对卡，也可以直接打字回怼，AI 答主即兴接招；第 2 轮后触发**对线时刻**，6 秒内必须站队，超时按弃权计；
5. **十二个月推演**：逐月左右滑动事件卡，存款/心态/机会/家人四维「体温」漂移但不显示数字；第 1 个月的选择会在后面引爆**延迟后果**；任一维见底触发**现实危机**，进行最后一次救赎选择；
6. **命运档案**：AI 结合知乎直答的社区参考口径与你的推演轨迹，产出可保存分享的命运卡 PNG。

## 三、整体技术方案

- **前端**：单页游戏（原生 JS + 编辑部纸张风设计系统），Next.js 14 托管与 API 路由；
- **围炉编译器** `/api/forge`：困境 + 约束牌 → 结构化游戏 JSON。带严格 schema 校验、程序化偏题检测（含短困境阈值修正与一次带反馈自动重试）、24 小时进程缓存、失败降级离线快照剧本（页面明确标注）；
- **打字回怼** `/api/rebuttal`：AI 以两位答主人格即兴接招，LLM 只判定交锋质量（击中要害/部分站住/被驳回），数值由确定性规则映射——模型不自由决定游戏数值；
- **知乎直答** `/api/zhida`：命运卡处给出「基于社区内容的参考口径」，与答主观点形成对照；
- **约束维度生成** `/api/constraints`：三个开局维度由 LLM 按困境动态生成（裸辞→存款/窗口/退路；异地恋→感情浓度/职业底气/父母阻力），处境与命运因人而异；
- **知乎登录（OAuth）**：授权码模式 + state 防 CSRF + HttpOnly 会话；登录后昵称进入围炉战绩，登录人数对接人气奖评定；
- **缓存与限额**：知乎热榜 100 次/天、搜索 1000 次/天、直答 100 次/天——全部应用层缓存（热榜 1h、编译 24h、直答 24h）+ 首页后台预编译热门困境 + 限频时 stale 缓存兜底。

## 四、使用的知乎开放能力

| 能力 | 用途 | 频控应对 |
|---|---|---|
| 热榜 `hot_list` | 首页「知乎热榜 · 实时争议」问题源 | 1 小时缓存，每天 <24 次调用 |
| 搜索 `zhihu_search` | 决策类真实问题补充源（含真实赞同/评论数） | 1 小时缓存 |
| 直答 Agent `chat/completions` | 命运卡处的社区参考口径 | 按困境 24h 缓存 |
| 知乎内容生态（回答/精选评论） | 答主论证风格与「典型观点」的孵化语料 | 仅使用短摘录与观点风格，不搬运全文 |

## 五、与知乎社区生态的契合点

1. **把社区的争论变成社区的游乐场**：知乎最独特的资产不是答案，是**立场鲜明的高质量争论**——本作品直接以争论为玩法核心。选题面基于真实社区观察覆盖当代困境六大圈层：职业生计（裸辞/35岁/考公）、学业选择（考研二战/第一学历）、情感婚姻（该不该结婚/异地恋）、家庭代际（原生家庭）、自我心理（精神内耗/空心感，心理健康居青年关注度前三）、金钱安全感；
2. **回应赛道主题**：官方期待中的「AI NPC 对话」（打字回怼）、「观点辩论训练 / 情景化练习」（围炉质询与对线）、「Agent 在社区的新角色：观点陪练」、「机制轻巧、易传播的原创玩法」（4 分钟一局 + 命运图分享）全部覆盖；
3. **回答知乎自己的老问题**：「在知乎搜『该不该』到底有没有用？」——本作品给出的答案是：别再匿名翻三百条回答，让代表性观点当面围炉，你亲自下场吵一架，然后自己拿主意。

## 六、对社区用户的实际价值

- **决策前**：一次 4 分钟的沙盘——把一条建议放到你自己的约束牌下推演一年，看清它的适用条件和崩盘点，替代低效的「刷三百条回答」；
- **决策后**：命运卡把你的选择变成可分享的故事，吸引更多人来围炉自己的困境，形成「真实问题 → 内容 → 新玩家」的社区内容循环；
- **对社区**：热门争议获得了一种新的消费形态（可玩、可围观、可传播），回答者的观点以「观点人格」的方式被重新激活（全程标注，不冒充真实用户）。

## 七、数据诚实性声明

热榜问题与互动数据来自开放平台实时接口；答主为 AI 孵化的观点人格，页面明确标注「AI 实时编译（非知乎历史）」，不伪造赞同数、不冒充真实用户、不把模型推测包装成社区历史；接口失败或额度耗尽时自动降级并如实提示。
